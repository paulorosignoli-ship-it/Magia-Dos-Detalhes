# Imagens do projeto

Estas imagens são arquivos estáticos do site e devem permanecer nesta pasta.

- `/images/hero-bg.jpg`
- `/images/block-clareza.jpg`
- `/images/block-fios.jpg`
- `/images/block-chaves.jpg`
- `/images/block-recompra.jpg`
- `/images/block-proximo.jpg`
- `/images/result-pattern.png`

No Next.js, arquivos dentro de `public/` são acessados pela URL a partir da raiz, portanto `public/images/hero-bg.jpg` é referenciado no código como `/images/hero-bg.jpg`.
